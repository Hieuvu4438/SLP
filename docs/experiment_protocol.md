# Experiment protocol

Rules that keep results correct and reproducible.

1. **Fixed splits.** Splits are created once in `src/slp/data/` with a fixed
   `split_seed`, independent of the run seed. Methods never re-split data.
2. **Shared evaluation.** Final metrics come only from `slp.evaluation`.
   Methods implement `fit(train, val)` / `predict(inputs)` and never see the
   evaluation targets.
3. **Val for development, test for reporting.** All tuning / model selection
   uses `--split val` (default). Run `--split test` only for final numbers,
   from a clean, committed tree; every test access is logged in
   `results/test_access_log.jsonl`.
4. **Multiple seeds.** Report mean ± std over ≥3 seeds (5 for main table).
   Same seed list for every method.
5. **Fair tuning budget.** Baselines get the same tuning budget / search
   space size as our method. Record the search space in the method README.
6. **Provenance.** Every run stores resolved config, git commit, dirty diff,
   command, host. A number in the paper must trace to a run dir and commit.
7. **Scripted experiments.** Every paper table/figure has a script in
   `configs/experiments/` and is regenerated by `scripts/aggregate.py`.
8. **Sanity baselines.** Every new method must beat trivial baselines (e.g.
   `baseline_majority`) before being considered.
